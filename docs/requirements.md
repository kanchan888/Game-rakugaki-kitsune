# らくがききつね 要件定義書 v1

## 1. ゲームの基本
- 遊び方: 線を描いて障害物コース(アスレ)をクリアする
- 進行: ステージ制、全30ステージ
- 主人公は自動で進み、ゴールに到達するとステージクリア
- 年齢制限なし

## 2. 線の形(枠とガチャ)
- ガチャで線の形を出す
- 出た形は、プレイヤーが枠に自分で選んで入れる
- 枠は初期3つ。コインで最大7つまで増やせる
- 枠を増やす費用は、増えるほど高くなる
- ガチャ1回の費用はコイン100
- ガチャに出る形の種類と出やすさは、とりあえず均等
- 具体的な数値(枠の費用・報酬)は試作で比較して決める

## 3. インク
- 初期インクは200
- 線を描くと墨が減る(1pxあたりの減り量は調整中。現在は0.3)
- インクがゼロになると線が描けなくなる
- インクのアイテムを拾うと100回復する(上限は200で仮置き)
- 失敗して残機が減ると、墨は200に戻る

## 4. コイン(ゲーム内通貨)
- 入手: ステージをクリアすると得られる
- 使い道: 枠を増やす、ガチャを回す
- 本物のお金は使わない

## 5. 残機と失敗時
- 残機は3機
- 失敗時は、そのステージのチェックポイントから再開する
- 失敗時は、描いた線をすべて消す

## 6. 描いた線
- 描いた線は、失敗するまでステージ内に残る(失敗時に全部消える)

## 7. 敵と味方
- 倒せる敵がいる
- 味方がいる
- 種類・動き・味方の役割は、試作してから決める

## 8. スターと隠しステージ
- 各ステージにスターが3個ある
- 各ステージに隠しステージが1つあり、そのステージのスター3個をすべて集めると遊べるようになる

## 9. 保存と再生
- 進行状況は次回の起動時も残す
- 再生はすべてのステージでできる
- 再生すると、そのステージは最初からになる

## 10. 対象と環境
- パソコン・スマホ・タブレットで遊べるブラウザ版

## 11. 名前と技術
- アプリ名・フォルダ名・リポジトリ名: らくがききつね / Game-らくがききつね
- 技術スタック: React + TypeScript + Vite
