# らくがききつね 要件定義書 v2

凡例: 【確定】=本人が決めた内容 / 【仮】=試作のための仮決め(後で変更しうる) / 【未決】=本人に確認が必要

## 1. ゲームの基本
- 遊び方: 線を描き、形を置いて障害物コース(アスレ)をクリアする 【確定】
- 主人公は自動で右へ進む。ジャンプ操作はない 【確定】
- 進行: ステージ制。全30ステージ 【確定】
- ゴールに到達するとステージクリア 【確定】
- 年齢制限なし。パソコン・スマホ・タブレットのブラウザで遊べる 【確定】
- 最初はチュートリアル面。クリアするとステージ1が解放される 【仮】
- 一時停止: EキーまたはEscキー 【確定】

## 2. 線と形(枠・ガチャ)
- 線の形はガチャで出す。ガチャ1回はコイン100 【確定】
- 出た形は、プレイヤーが枠に自分で選んで入れる 【確定】
- 枠は初期3つ。コインで最大7つまで増やせる。増やす費用は増えるほど高くなる 【確定】
- 枠に入った形を選んで、画面をクリックして置く。何回でも置ける。置くたびに墨を消費する 【確定】
- ガチャに出る形の種類と出やすさは、とりあえず均等 【確定】
- 形の絵: 枠と持ち物の一覧に、形ごとの絵を出す 【確定】

### 2-1. 形の一覧
| 形 | 能力 | 状態 |
|---|---|---|
| 足場 | 上に乗れる | 実装済 |
| ジャンプ台 | 上から乗ると跳ね上がる | 実装済 |
| 加速 | 乗ると速く進む(×1.8) | 実装済 |
| 減速 | 乗るとゆっくり進む(×0.5) | 実装済 |
| ふわふわ | 触れると落下がゆっくりになる | 実装済 |
| 赤信号 | 置くと、右に線1個分の光が出る。主人公が光に当たると3秒止まり、赤信号は消える | 実装済(仮) |
| 動く足場 | 置いた位置を中心に左右へ90pxの範囲を往復する。乗っている主人公も一緒に動く | 実装済(仮) |
| ロボット | 置いて8秒後に、左右200px以内の敵を倒して消える | 実装済(仮) |
| あな | 置いた場所の地面に穴を開ける(線にはならない)。落ちると残機が1減る | 実装済(仮) |
| エレベーター | 触れると「上へ/下へ」を選ぶ。選んだ方向へ180px動いて止まる | 実装済(仮) |
| 扇風機 | 上へ風を出す(高さ220px)。風に当たると吹き上げられ、右へも少し押される | 実装済(仮) |
| 紙飛行機 | 乗ると、矢印キー(WASD)で自由に動かせる。上下キーを離すと重力で落ちる | 実装済(仮) |
| ライト | 置くと周囲220pxを照らす。暗くする敵が出たときに、その暗さを打ち消す | 明かり表示のみ(仮) |

### 2-2. 形の仮決め(要確認)
- 「あな」: 地面に穴を開ける道具として実装した。敵を落とす使い方なのか、主人公の道具なのか【未決】
- 「ロボット」: 置いて8秒後に一括で倒す仕様にした。8秒で1体を倒す仕様なのか【未決】
- 「紙飛行機」: 操作は矢印キーにした。マウスで動かす方が良いか【未決】
- 「ライト」: 今は明かりの表示だけ。暗い敵との組み合わせで効果を出す予定【未決】

## 3. 形のレベルアップ 【未実装】
- 形は、使うとレベルが上がり、能力が強くなる 【確定】
- レベルの上げ方・上限・強くなる数値は未定 【未決】(例: 同じ形を複数持つと合成する / コインで上げる)

## 4. インク
- 初期インクは200 【仮】
- 形を置くと墨が減る(1回30) 【仮】
- 自由に線を描くと墨が減る(1pxあたり0.3) 【仮】
- 墨がゼロになると、形を置けなくなり線も描けなくなる 【確定】
- インクのアイテムを拾うと100回復する(上限200) 【仮】
- 味方がいる間は、墨が1秒あたり8回復する 【仮】
- 失敗して残機が減ると、墨は200に戻る 【確定】

## 5. コイン(ゲーム内通貨)
- 入手: ステージをクリアすると100得る 【仮】。最初の持ちコインは100 【確定】
- 使い道: 枠を増やす、ガチャを回す 【確定】
- 本物のお金は使わない 【確定】

## 6. 残機と失敗時
- 残機は3機 【確定】
- 失敗時は、そのステージのチェックポイントから再開する 【確定】
- 失敗時は、描いた線と置いた形をすべて消す 【確定】
- 失敗時は、地面の穴も元に戻る 【仮】
- 失敗の原因: 敵にぶつかる / 穴に落ちる / 行き止まり 【仮】

## 7. 敵
- 左右に歩く敵: 決められた範囲を往復する 【確定】
- 上から踏むと倒せる。横からぶつかると残機が1減る 【確定】
- 倒した敵は、失敗すると元の位置に戻る 【確定】
- ステージ4から敵を置く 【確定】
- 追加予定の敵(未実装):
  - 上や下に飛ぶ敵 【確定】
  - 偽の地面を作る敵 【確定】
  - 周りを暗くする敵 【確定】(暗さはライトで打ち消す案) 【未決】
  - 具体的な動きは未定 【未決】

## 8. 味方
- 味方は主人公の後ろについてくる 【確定】
- 味方の役割(今は墨の回復):
  - 墨を回復する 【確定】
  - 線を太くする 【確定】(役割の切り替え方・同時に持つか 【未決】)
- 味方は失敗すると、主人公の後ろに戻る 【確定】

## 9. スターと隠しステージ
- 各ステージにスターが3個ある 【確定】
- 各ステージに隠しステージが1つあり、そのステージのスター3個をすべて集めると遊べるようになる 【確定】(隠しステージは未実装)
- スターの位置は、地面からでも取れる高さに置く 【仮】

## 10. ステージ
- 試作済み: チュートリアル、ステージ1、ステージ2 【確定】
- 追加: ステージ7個(ステージ3〜9)を作る 【確定】
- ステージ4から敵を置く 【確定】

## 11. 保存と再生
- 進行状況は次回の起動時も残す 【確定】
- 再生はすべてのステージでできる 【確定】
- 再生すると、そのステージは最初からになる 【確定】

## 12. 名前と技術
- アプリ名・フォルダ名・リポジトリ名: らくがききつね / Game-らくがききつね 【確定】
- 技術スタック: React + TypeScript + Vite 【確定】
